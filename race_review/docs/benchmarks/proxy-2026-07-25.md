# Full-chapter proxy benchmark attempt

Date: 2026-07-25

## Scope

This run targets the complete `GX020115.MP4` chapter with the production proxy
profiles. It supersedes neither the successful bounded verification nor its quality
decision in [the GTX 1070 benchmark](proxy-2026-07-18.md). The comparison remains
incomplete until both full CPU and CUDA rows are measured on a healthy NVIDIA host.

- Source: 3840x2160 HEVC at 60000/1001 fps, 534.534 seconds, 4,006,805,630 bytes
- CPU: Intel Core i5-9600K, 6 cores
- GPU expected by the prior host run: NVIDIA GeForce GTX 1070, 8 GiB
- FFmpeg: Ubuntu 4.4.2
- Proxy profile: `h264-1080p60-aac-gop2s-v3`
- Seek method: FFmpeg input seek followed by one decoded video frame, three repetitions
  each at 5 seconds, the chapter midpoint, and five seconds before the end

## Reproduction

The benchmark is implemented by `scripts/benchmark_proxy.py` and directly uses
`build_proxy_command`, so its encoder, scaler, audio, GOP, and muxing options are the
same as an application import. It writes a machine-readable JSON report after each
backend, preserving the CPU measurement if a later CUDA run fails.

Run both backends from `race_review`:

```console
uv run python scripts/benchmark_proxy.py ../data/GX020115.MP4 \
  --output-dir var/benchmarks/proxy/full-2026-07-25
```

Use `--backend cpu` or `--backend cuda` to isolate one profile. The generated proxies
and JSON report are local benchmark artifacts under the ignored `var/` directory.

## CUDA blocker

The sandboxed `nvidia-smi` probe failed with “couldn't communicate with the NVIDIA
driver.” An approved host `nvidia-smi` then entered uninterruptible `D` state as PID
344749 in `os_acquire_rwlock_write`. A bounded NVENC smoke test also became stuck:
PID 347882 is the `timeout 15s` parent and PID 347883 is FFmpeg in `DLl` state at
`os_acquire_rwlock_write`. The timeout cannot terminate a task blocked in the NVIDIA
kernel path. No full CUDA encode was started after this condition was confirmed.

This is a host/driver availability failure, not an encoder result. The full comparison
TODO must remain open, and no CUDA measurements should be inferred from the earlier
30-second run. Recover the NVIDIA driver (typically by rebooting the host), verify
`nvidia-smi`, then rerun the command above.
